Outreach

Kontakt- und Aufgabenmanager für GNOME

Version 0.0.3 · Build 2026-09-05

Installation

Füge dieses Repository als Quelle hinzu und installiere die App:

flatpak remote-add --if-not-exists outreach \
  https://dspangenberg.github.io/outreach/outreach.flatpakrepo
flatpak install --user outreach de.twiceware.outreach

Oder 1-Klick-Installation über die Referenzdatei:

https://dspangenberg.github.io/outreach/outreach.flatpakref
